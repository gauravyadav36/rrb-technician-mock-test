# RRB Technician Grade 3 Mock Test

## Features
- Randomized mock tests
- Subject-wise practice modes
- Timed exam with auto-submit
- Negative marking support
- Study notes with search and formula display
- PDF generation from the browser
- Offline-first caching via service worker

## Running locally
npm install
npm run dev

## Deploying to GitHub Pages
npm run build
npm run deploy
